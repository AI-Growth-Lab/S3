# `data/`

This folder is for input datasets, but **large raw bibliographic exports are intentionally
git-ignored** (see the repository `.gitignore`). Commit only:

- small sample/example data needed to run a demo, or
- scripts that fetch/regenerate the data from a query (preferred for reproducibility).

For any analysis, record the **database**, the **exact query**, and the **retrieval date** so others
can reproduce the corpus. See [`../docs/data-format.md`](../docs/data-format.md).
