# Analysis proposals

This folder is the catalogue of **analysis ideas** for the S3 project and their status. Each idea
starts as an issue; accepted ideas are recorded here as a markdown file and (where validated) built
into [s3-bibliometric.com](https://s3-bibliometric.com/).

➡️ **To propose an idea, open a [💡 Analysis idea issue](../../../issues/new/choose).** You do not
need to write code. See [`../docs/proposal-process.md`](../docs/proposal-process.md) for the full
lifecycle and how crediting works.

## Status legend

| Status | Meaning |
|--------|---------|
| 💡 Idea | Submitted, awaiting discussion |
| 💬 Discussing | Being refined with the community/authors |
| 🔬 Testing | Authors are prototyping it on the app/data |
| 🚀 In app | Implemented and live in the app |
| 🗄️ Parked | Not feasible/robust yet; kept for the future |

## Adding a proposal file (optional)

1. Copy `TEMPLATE.md` to `NNNN-short-name.md` (next free number).
2. Fill in the metadata and sections.
3. Add a row to the catalogue table above.
4. Open a pull request (this is also how you get added to the contributor history).
