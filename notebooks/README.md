# `notebooks/`

Exploratory and analysis notebooks. Good places for:

- end-to-end walkthroughs of the S3 pipeline on a sample corpus,
- new domain analyses (also add a short summary to `examples/`),
- figures and robustness checks.

Please clear large outputs before committing (`jupyter nbconvert --clear-output`), and keep raw
data out of the repo (see [`../data/README.md`](../data/README.md)).
