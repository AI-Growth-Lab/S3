# `examples/`

Worked examples and shareable analyses. Each example folder should contain:

- a short `README.md` describing the field, the database + queries used, and the retrieval date,
- the script or notebook that produces the map,
- small derived outputs (community tables, figures) — but **not** large raw exports.

The paper applies S3 to two domains (*Innovation and Diversity* and *Ecosystems in Business*);
contributing additional domains is a great first contribution.
